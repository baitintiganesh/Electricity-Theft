About the Project

The Electricity Theft Detection System is a robust machine learning-based web platform designed to identify unauthorized electricity usage in power grids. It uses multiple advanced models like Random Forest, XGBoost, SVM, ANN, and Decision Trees to detect anomalies from consumption patterns.

The project applies data preprocessing, standardization, and real-time prediction with alarm triggers. It provides a secure admin login system and a futuristic UI powered by Flask and HTML/CSS.

Designed for scalability and accuracy, the system is highly efficient in identifying potential electricity theft cases and alerting the admin through an intuitive dashboard and sound alarm. The project is suitable for smart city applications and utility agencies.
